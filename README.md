# WIMIT College Website

A responsive, dependency-free landing page for WIMIT College.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive styling
- `script.js` — mobile navigation and current year

## GitHub Pages
1. Create a new GitHub repository, e.g. `wimit-college`.
2. Upload `index.html`, `styles.css`, `script.js`, and this README.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then **Save**.
6. GitHub will publish the site at `https://YOUR-USERNAME.github.io/wimit-college/`.
